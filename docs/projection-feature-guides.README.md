Projection feature guide interactions

- Feature descriptors are grouped into three visual sections: center structure | symmetry | radial structure.
- Hovering or focusing the symmetry-axis descriptor overlays the detected reflection axes on the projection stage.
- Hovering or focusing the radial-layer descriptor overlays concentric guide rings for the detected nested convex layers.
- Guide overlays are non-interactive (`pointer-events: none`) so projection dragging and class navigation keep their existing behavior.
